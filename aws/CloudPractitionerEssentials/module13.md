# Module 13 - Well-Architected Solutions

## Development

### AWS CodeBuild

Is a fully managed continuous integration that compiles source code, runs, tests, and produces software packages for deployment.

Is auto-scale, pay for the build time.

### AWS CodePipeline

Is a fully managed CI/CD service that automates the build, test, and deploy phases.

### AWS X-Ray

Tracing, debugging, and performance analysis tool to monitor applications.

### AWS AppSync

Is a fully managed [GraphQL](../../Web/README.md#graphql) service.

### AWS Amplify

It helps streamline the process of developing, deploying, and managing full-stack applications on AWS.

## Business Application

### Amazon Connect

It's an AI-powered contact center service to set up and operate a scalable customer service call center (Ticketing platform).

It provides call routing, recording, and analytics.

### Amazon Simple Email Service (SES)

Is an email service provider that can be integrated into any application.

## End-user Computing

### Amazon AppStream 2.0

Is a fully managed service that streams applications from the cloud to any compatible device, including [SaaS](../../CloudCompute/architectures/README.md#software-as-a-service-iaas).

This provides instant access to software without the need for high-end local hardware.

### Amazon WorkSpaces

Is a fully managed cloud-based desktop computing service.

With WorkSpaces, employees can access their work environment from any device.

### Amazon WorkSpaces Secure Browser (WorkSpaces Web)

Is a fully managed remote enterprise browser.

The user can access private websites, SaaS, and the public internet protected.

## Internet of Things (IoT)

### AWS IoT Core

Is a managed service used to securely connect physical devices with cloud applications.

It helps with the complex process of ingesting, processing, and acting on device data.

## Well-Architected Framework

- **Operational Excellence**: Operations, monitoring, automation, and continuous improvement;
- **Security**: Protects system and data through best practices;
- **Reliability**: Emphasizes recovery planning and system adaptability;
- **Performance Efficiency**: Encourages using the right resources;
- **Cost Optimization**: Helps control and reduce costs through smart provisioning and resource management;
- **Sustainability**: Promotes energy efficiency;

### AWS Well-Architected Tool (WA Tool)

Is a free service that helps assess and improve cloud workloads.

It offers workloads reviews, milestones tracking, and custom lenses for evaluations and improvement plans.

It promotes consistent, actionable, and well-documented architecture reviews.
